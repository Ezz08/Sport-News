# Sport News

A modern and responsive Sports News Landing Page designed to present sports content in a clean, engaging, and user-friendly interface.

The website brings different types of sports content together, including trending news, recent updates, club rankings, sports articles, and newsletter subscription.

## About The Project

Sport News is a front-end practice project focused on building a complete sports news landing page using HTML5 and CSS3.

The main goal of the project was to practice creating a multi-section website, working with different layouts, organizing content, handling images, and building a responsive user experience.

## Features

* Hero section with featured sports content
* Sports categories:

  * Football
  * Basketball
  * Car Sport
  * Table Tennis
* Trending news section
* Featured football article
* Recent news section
* Clubs ranking table
* Sports articles section
* Newsletter subscription section
* Responsive navigation menu
* Responsive layout for different screen sizes

## Technologies Used
